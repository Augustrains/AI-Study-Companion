# 资料问答检索与拒答手工测试用例

## 1. 测试目标

本文档用于验证资料问答的两层能力：

1. **检索层**：问题与当前教材相关时，能否召回正确章节和文本片段。
2. **生成层**：回答能否忠于检索内容、正确标注 `[资料N]`，并在资料不足时明确拒答。

测试资料来自当前应用实际配置的两个目录：

- `bookId=ml`：`data/question_new/教材/ML-For-Beginners/lessons`
- `bookId=dl`：`data/question_new/教材/AI-For-Beginners/lessons`

## 2. 执行方法

1. 启动后端和前端，进入“资料问答”。
2. 按用例要求选择《机器学习》或《深度学习》。
3. 每组测试开始前点击“新建对话”，避免历史上下文影响结果。
4. 记录回答、引用标题、引用位置和引用摘要。
5. 连续追问用例必须在同一个会话中按顺序执行。

每条用例按以下三个维度记录结果：

- `检索：通过/失败`
- `回答：通过/失败`
- `备注：实际召回文件、异常或幻觉内容`

**真实资料依据**

- `ml-unit-001.md`
- 关键内容：监督学习使用带标签的数据；分类预测类别；回归预测连续值；垃圾邮件识别和二手车价格是教材示例。

**通过标准**

- 引用中至少有一个片段来自 `ml-unit-001.md`。
- 回答包含“标签”“类别”“连续值”等核心含义。

## 8. 总体判定建议

- **检索通过**：相关问题的前 5 个引用中至少有一个来自预期章节，且摘要包含回答所需事实。
- **生成通过**：回答主要结论能由引用摘要支持，没有补充无法追溯的事实。
- **拒答通过**：无关问题明确拒答，不输出实质性外部答案，也不伪造资料支持。
- **教材隔离通过**：只在当前 `bookId` 对应目录检索，不借用另一教材的内容。

> 当前检索实现固定返回 Top-5，尚未设置最低相关度阈值。因此无关问题可能仍返回“最相近但实际无关”的教材片段。若回答成功拒绝但 `citations` 仍非空，应记录为“生成层通过、检索层失败”。
