# 第一版清洗资料库

本资料库是第一版问答优先检索的资料源。每份资料均应由内容人员复核，并标明对应书籍、章节和知识点。

运行版使用轻量关键词检索来演示“先查书籍资料，再提示通用 AI 补充”的用户体验；后续可替换为向量检索，不改变题库和状态判断边界。

## 使用边界

- 本目录资料用于学习讲解和问答引用。
- 正式诊断与复测仍只使用 `../data/question_bank.csv` 中 `approved` 的人工审核题目。
- 问答不能直接改变任何知识点的 AI 判断或掌握状态。
- `待审核/` 中的内容只是从已授权原始资料中抽取出的候选单元；当前 27 个第一版单元均已发布到 `正式/`。后续重新清洗或新增单元时，候选单元必须重新审核，只有 `review_status=approved` 的单元才可被称为正式学习资料。

## 审核与发布检查

运行 `npm run audit:readiness` 可查看每本书的正式资料、待审核单元和题库覆盖缺口；运行 `npm run verify:release` 会在存在发布阻塞项时失败。内容负责人完成审核后，必须同时更新 `content_unit_catalog.csv` 的状态、资料文件的前置元数据和相应测试，再重新执行检查。
