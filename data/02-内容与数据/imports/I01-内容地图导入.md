# I01：书籍、能力与知识点地图导入

## 人工填写文件

- `../data/book_catalog.csv`
- `../data/ability_knowledge_edges.csv`

## 必填关系

```text
Book
→ Topic
→ Ability
→ KnowledgePoint
→ PrerequisiteKnowledgePoint（可为空）
→ Chapter / Source
```

## 技术校验

```text
1. book_id、ability_id、knowledge_point_id 必须唯一且存在。
2. 每个 active 知识点必须绑定至少一个能力和一个书籍主题。
3. prerequisite_knowledge_point_id 必须引用同一书籍范围内存在的点，或明确声明跨书复用。
4. 前置关系不能形成环。
5. status 只允许 active / planned / disabled。
```

## 导入输出

```text
content_graph_version
valid_nodes[]
valid_edges[]
validation_errors[]
```

导入成功后，A01 才能读取该版本的能力—知识图。
