# I04：开放教材清洗与导入

## 目标

把合法来源的教材，转换为可追溯的学习内容单元；而不是把整本 PDF 或 Git 仓库直接塞入 RAG。

## 固定处理顺序

```text
source_catalog.csv 固定来源、许可证和提交版本
→ 目录清单确认章节范围
→ 章节/小节切分为 content unit
→ 去除导航、广告、构建残留和无关代码输出
→ 保留标题、正文、必要公式/代码、来源和许可证
→ 标注能力、知识点、前置关系、预计时间和任务类型
→ 内容负责人审核后才允许进入资料问答和学习页面
```

## 每个内容单元的必填字段

- `content_unit_id`：稳定 ID。
- `source_id`、`source_relative_path`、`source_commit`：可回到原始资料。
- `book_id`、`topic_id`、章节/小节标题。
- `knowledge_point_ids`：一个或多个已存在的知识点。
- `learning_objective`、`estimated_minutes`、`content_type`。
- `license`、`attribution`、`cleaning_status`、`reviewer`、`reviewed_at`。

## 不允许的做法

- 不导入未授权教材、来路不明 PDF 或盗版扫描件。
- 不删除署名、许可证和原始出处。
- 不把未审核的模型摘要当成教材正文或正式题目。
- 不把原始仓库的图片、缓存、构建产物和所有代码输出直接放入 RAG。

## 当前第一轮范围

- 机器学习：Ocademy 的“机器学习概览、回归、分类、损失函数、梯度下降、聚类、集成学习、模型选择”。
- 深度学习：D2L 的“预备知识、线性网络、多层感知机、卷积神经网络、循环神经网络”。

这是一轮可用学习路径的内容范围；后续可继续导入更高阶章节，但应先保证本轮每个知识点均具备学习内容、练习和正式复测。

## 本地执行

在项目根目录运行 `npm run prepare:content`。脚本只从 `原始资料/` 中读取 `content_unit_catalog.csv` 已登记的路径，输出到 `资料库/待审核/`；它不会自动批准内容或生成正式题目。内容负责人审核后，将合格单元移入正式资料库并更新 `review_status`。
