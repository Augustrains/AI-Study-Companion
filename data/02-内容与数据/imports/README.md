# 资料导入工作流

资料导入不是“上传文件后交给 RAG”。它是人工内容工作与算法输入的正式生产流程。

## 三条导入线

| 导入线 | 人工准备 | 系统校验 | 输出给谁 |
|---|---|---|---|
| I01 内容地图 | 书籍、章节、能力、知识点、前置关系 | ID 是否存在、是否成环、章节是否归属书籍 | A01、RAG |
| I02 题库 | 题目、答案、评分规则、目标等级、出处 | 标签完整、答案存在、题目状态、重复题 | A02、A03 |
| I03 RAG 资料 | 已授权资料、版本、目录、标签 | 可解析、来源完整、片段标签完整 | A06 |

## 导入顺序

```text
book_catalog.csv
→ ability_knowledge_map.csv
→ question_bank.csv
→ rule_config.yaml
→ 第一版资料问答资料与元数据
```

## 人工完成标准

- 每个知识点必须属于一个能力，且能关联至少一本书。
- 每道正式题必须至少绑定一个能力和一个知识点。
- 每道题必须有标准答案、评分规则、目标等级和资料出处。
- 所有资料必须确认版权或使用权限。
- `draft` 题不得进入正式诊断；仅 `approved` 题可被 A02 使用。

详细格式见 `../data/` 中的 CSV 模板和 `I03-RAG资料导入.md`。
