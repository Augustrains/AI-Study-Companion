# I02：题库与评分规则导入

## 人工填写文件

- `../data/question_bank.csv`
- `../data/rule_config.yaml`
- `../data/question_delivery_profile.csv`
- `../data/question_wrong_option_review.csv`
- `../data/mastery_task_scoring_card.csv`

## 每道正式题的最小要求

```text
question_id、book_id、topic_id、target_level、question_type、difficulty
question_summary、prompt、options_json、correct_option、answer_key、explanation
scoring_rule、source_note、version、status=approved
```

## 技术校验

```text
1. 题目必须通过 `question_knowledge_edges.csv`、`question_ability_edges.csv` 和 `question_source_edges.csv` 关联知识点、能力和教材出处。
2. target_level 只允许：基本了解 / 熟悉 / 掌握。
3. status=approved 时，答案、评分规则、出处不得为空。
4. 同一题目版本不可重复；修改题干、答案或规则必须递增版本。
5. 每道题必须有 `question_delivery_profile.csv` 用途和曝光规则；每个错误选项必须出现在 `question_wrong_option_review.csv`。
6. 代码题需要指定隔离执行环境与可执行测试用例；非选择题必须登记 `mastery_task_auto_grading_spec.csv`，以答案键、容差、结构化字段或测试实现实时自动评分，不能依赖人工实时评分流程。
```

## 导入输出

```text
question_bank_version
approved_questions[]
draft_questions[]
validation_errors[]
coverage_report
```

A02 只读取 `approved_questions`；A03 只使用对应版本的 `scoring_rule`。
