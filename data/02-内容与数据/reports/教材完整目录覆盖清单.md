# 两本教材完整目录覆盖清单

更新时间：2026-07-31  
用途：将“当前可学习的基础路径”与“完整教材目录”明确区分；内容负责人据此按目录补资料、知识点、题库与人工掌握任务，产品不得将未覆盖内容表述为已完整交付。

## 当前结论

- 当前正式范围是 **27 个已审核教材单元**、35 个必学知识点，以及 Python 编程基础和 Q 表实现两个推荐前置点。
- 这是一条可运行的基础学习路径，**不是两本原始教材的完整目录**。任何新增目录项必须按“资料单元 → 知识点/能力边 → 题目蓝图 → 客观题 → 开放掌握任务 → 人工校准”完整入库。

## 每个新目录项的交付检查

1. 记录来源 URL、许可证、固定版本、章节锚点与内容审核人。
2. 建立书籍 → 章节 → 小节 → 知识点 → 能力的多对多关系；明确必学或推荐范围。
3. 为每个必学知识点登记不少于 4 个独立客观题版本、至少 3 类题型和 1 个无提示复测题。
4. 为“掌握”新增至少 1 个可自动判分的应用任务（结构化短答、推导、调试、实现或案例建模之一），写明提交字段、答案键或测试用例。
5. 内容负责人完成题目人工校准后，才可将该知识点的 `question_quality_gate.csv` 改为 `eligible`。
