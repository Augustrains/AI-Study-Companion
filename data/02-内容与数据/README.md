# 02 内容与数据

本模块是人工维护的事实来源：书籍、能力、知识点、前置关系、正式题库和清洗资料都在这里准备，再由服务和算法读取。

## 当前内容状态

- 第一版资料源已固定：机器学习使用 Ocademy 的 *Open Machine Learning Book*（CC BY 4.0），深度学习使用《动手学深度学习》中文版（Apache-2.0）；版本、许可证与原始链接见 `data/source_catalog.csv`。
- `原始资料/`：本机下载的原始开放教材（不提交 Git）；按 `原始资料/README.md` 可复现下载。
- `data/`：书籍、章节单元、能力—知识点地图、题库、边关系和规则配置。
- `资料库/待审核/`：由 `npm run prepare:content` 从原始教材抽取的 27 个 Markdown 单元，保留为可复现的审核工作区；修改后须重新审核，不会自动发布。
- `资料库/正式/`：已发布的 27 个正式教材单元，均保留来源、许可证、章节、学习目标、知识点标签和审核信息；运行服务优先以它们提供阅读和资料问答。
- `reports/教材完整目录覆盖清单.md`：声明当前基础路径的目录边界与后续补齐顺序，避免把精选单元误称为完整教材。
- `资料库/` 根目录中的 4 篇短 Markdown 是早期讲解示例；正式学习路径以 `资料库/正式/` 的教材单元为准。
- `imports/`：新增书籍、题库和开放教材的导入与审核要求。

当前两本书均以“基础学习路径”运行：机器学习含 17 个必学知识点，深度学习含 18 个必学知识点。每个必学知识点已有至少 4 道独立 `approved` 题，覆盖其蓝图规定的概念、应用、推导、代码、建模、评价或复测证据；但在内容负责人填写人工校准前，`question_quality_gate.csv` 会阻止系统自动升级为“掌握”。首次诊断仍是能力抽样，未测内容保持“未测评”。

## 内容人员交付标准

1. 每道正式题必须有题干、选项、标准答案、评分规则、知识点/能力标签和资料出处，且只有审核后才可设为 `approved`。
2. 每个必学知识点至少有可用于诊断或复测的题目；发现缺口时补题，不用大模型临时题替代。
3. 每份资料问答材料必须标注书籍、章节和关联知识点。
4. 修改后运行项目根目录 `npm test`，确保资料和题库能被服务读取。
5. 不得把模型临时生成的题目、摘要或未经审核的 `待审核/` 内容标记为 `approved`。
