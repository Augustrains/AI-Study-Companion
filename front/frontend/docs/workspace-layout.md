# 桌面工作区布局

## 行为

- 桌面应用框架固定为当前浏览器可视高度，不随课程、表单或社区内容增长。
- 左侧导航和底部账户入口留在窗口内；右侧顶部课程选择器、页面标题及横幅随内容一起滚动。
- 右侧 `page-content` 从窗口顶部延伸到底部，最右侧滚动条从顶部开始，可通过滚轮、滚动条或聚焦后的键盘翻页查看完整内容。
- 社区分类栏滚动到顶部后轻量吸顶；搜索框、伙伴推荐及小组卡片保持正常滚动，不叠加固定面板。
- 切换页面或课程后，右侧滚动位置归零；不额外重建页面组件，也不修改学习数据。
- 小高度桌面窗口中，导航列表必要时可以单独滚动，账户入口仍可访问。
- 本次只调整桌面（821px 及以上）的公共布局，不新增手机端，也不改变登录页布局。

## 实现

- `src/workspace-layout.css`：视窗高度、公共 Flex 布局和滚动容器，放在现有主题之后加载。
- `src/App.tsx`：将顶部课程栏与 `page-body` 放进同一个 `page-content` 滚动容器，通过 ref 在切页 / 切课后复位滚动位置。
- `src/components/CommunityView.tsx` 与 `community.css`：分类栏直接属于动态流容器，使吸顶范围覆盖动态列表；为键盘滚动预留顶部空间，避免焦点被分类栏遮挡。
- 不锁死文档根节点的滚动，不影响未登录页面、系统弹窗和原有表单。

## 本次浏览器验收

- 1280×720 下，文档、应用和右侧滚动区域高度均为 720px；滚动区域顶部坐标为 0。
- 社区内容总高度超过 2500px；向下滚动 800px 后，文档仍为 720px，左侧导航顶部为 0，课程栏顶部为 -800px，分类栏吸顶位置为 0。
- 1024×768、1440×900 下，文档宽高与视窗一致，无整页横向溢出，右侧滚动区域仍占满视窗高度。
- 社区筛选后结果可见，发布弹窗居中且 Escape 关闭后焦点返回触发按钮。
- 学习画像长表单滚动至底部可访问保存按钮；未保存输入保持不变。
- 今日学习、画像、诊断、计划、记录、资料问答、资源、选书与目标、设置、帮助、社区使用同一滚动框架。
- 逐页检查布局高度、切页后 scrollTop=0、内容可访问及固定导航。
- 原有社区状态回归测试及前端生产构建均通过。

此修改仅在本地预览与工作分支中生效，是否上传以仓库发布流程为准。
