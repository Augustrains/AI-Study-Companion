# 前端实现边界与运行说明

## 学习社区（纯前端演示）

侧栏新增「学习社区」，支持动态筛选、发帖、评论、点赞、收藏、学习搭子关注和小组加入。社区使用虚拟数据，操作按账号保存在本地浏览器，不新增后端接口。运行方式与验收步骤见 [学习社区说明](docs/community-demo.md)。

## 前端基础环境

本目录使用 React + TypeScript + TSX + Vite + Tailwind CSS。

```bash
npm install
npm run dev
```

当前版本已经完成可点击前端页面演示，包含：

- 学习内容：仅展示《机器学习》和《强化学习》，切换后页面内容会同步变化。
- 今日学习：本周进度、今日推荐任务、能力图谱、今日任务详情。
- 能力诊断：逐题保存、上一题、跳过、暂停、继续、提交、失败提示。
- 测评结果：AI 评估、依据详情、用户校准和原因保存。
- 学习计划：任务详情、开始、完成、目标调整、计划总览和知识点列表。
- 学习记录：分类筛选、事件详情和复测入口。
- 资料问答：等待状态、失败重试、历史对话、资料引用、来源预览和加入计划。
- 设置与帮助：使用弹窗预留用户偏好和产品说明模块。

页面默认使用模拟服务，真实接口统一预留在 `src/services/api.ts`。设置 `VITE_USE_REAL_API=true` 后可以切换为后端接口，并通过 `VITE_API_BASE_URL` 指定后端地址。

后端交接说明位于上级目录的 `docs/前端交互与后端交接说明.md`。

第一版页面：

```text
1. 今日学习页
2. 诊断答题页
3. 测评结果与用户校准页
4. 学习计划页
5. 学习记录与复测页
6. 资料问答页
```

前端只负责输入、展示、确认和触发动作；不在浏览器中自行定义掌握规则。

每个状态都应能展示“依据”：题目、标签、来源、作答结果、判断时间、用户校准原因。

## 交接方式

页面组件只负责展示、输入和触发动作，统一通过 `src/services/api.ts` 调用服务。后端接入时不需要重做页面，只需：

1. 设置 `VITE_USE_REAL_API=true`。
2. 设置 `VITE_API_BASE_URL`。
3. 按上级目录 `docs/前端交互与后端交接说明.md` 返回稳定字段和状态。

如果后端返回字段与页面模型不同，只在服务层增加数据转换，不把数据库字段直接传入页面组件。
