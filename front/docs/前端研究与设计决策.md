# 前端研究与设计决策

## 文档状态

- 版本：v0.1
- 阶段：交互研究与视觉设计阶段
- 当前结论：暂不进入业务代码开发，先确认效果图和交互方案
- 前端技术方向：React + TypeScript + TSX + Vite + Tailwind CSS

## 1. 研究范围

本轮重点研究 GitHub 上的学习平台、智能辅导系统和 AI 学习产品，关注以下问题：

- 用户如何从学习目标进入具体任务。
- 诊断题如何逐题推进并提供反馈。
- 系统如何解释“为什么推荐这个任务”。
- AI 判断与用户自我判断如何并存。
- 学习任务完成后如何进入复测或下一轮计划。
- AI 问答如何展示资料引用和后续动作。

## 3. 设计决策

### 3.1 产品名称

统一使用：

> 自适应伴学智能体

不使用“伴侣”等容易产生情感产品联想的名称。

### 3.2 视觉方向

- 主色：清新蓝色。
- 基础色：白色、冰蓝色、浅灰蓝色。
- 文字：深蓝灰色，保证阅读对比度。
- 成功状态：低饱和绿色。
- 待复测状态：少量琥珀色提示。
- 避免：紫色主色、米黄色背景、过度渐变、装饰性人物和吉祥物。

### 3.3 信息架构

左侧主导航固定为：

1. 今日学习
2. 能力诊断
3. 学习计划
4. 学习记录
5. 资料问答

顶部固定显示“当前书籍”和当前学习目标，避免用户在不同页面中丢失学习上下文。

### 3.4 交互原则

- 每个页面只设置一个主要行动。
- 所有推荐任务都要能查看推荐原因。
- AI 评估和用户校准必须分开显示和保存。
- 前端只展示后端结果，不在浏览器中重新计算掌握规则。
- 完成操作后，要告诉用户下一步是什么。
- 所有异步操作都要有加载、成功、失败和重试状态。
- 重要的不可逆操作需要二次确认；普通学习记录允许继续和恢复。

## 4. 页面优先级

### 第一阶段

1. 今日学习
2. 选书与目标
3. 能力诊断
4. 测评结果与用户校准
5. 学习计划
6. 学习记录与复测

### 第二阶段

7. 资料问答
8. 知识图谱详情
9. 学习趋势与长期分析

## 5. 交互闭环

```text
当前书籍与目标
  → 能力诊断
  → AI 评估与依据
  → 用户校准
  → 生成学习计划
  → 完成学习任务
  → 写入学习事件
  → 到期复测
  → 下一轮学习建议
```

## 6. 研究后的最终建议

首页不应只是数据看板，而应成为“下一步行动页”。用户打开页面后，应立即知道：

- 我现在学习什么。
- 我当前最需要完成什么。
- 系统为什么这样推荐。
- 完成后会发生什么。

这会比堆叠大量图表更符合自适应伴学产品的核心价值。
